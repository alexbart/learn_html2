# Wonderful Bites Menu 🍽️

A simple HTML restaurant menu webpage built as part of an HTML learning project.

📌 **Repository:**  
https://github.com/alexbart/learn_html2

---

## Project Overview

**Wonderful Bites Menu** is a static webpage that showcases a fictional restaurant menu.  
The project demonstrates the use of **semantic HTML**, lists, images, forms, and external CSS styling.

It is designed for beginners learning how to structure webpages using HTML.

---

## Features

- Hero section with restaurant name and welcome message
- Menu divided into clear sections:
  - Appetizers
  - Main Courses
  - Desserts
- Each menu item includes:
  - Food image
  - Item name
  - Price in Kenyan Shillings (KES)
  - Short description
- External CSS styling
- Contact form in the footer

---

## Technologies Used

- HTML5
- CSS3
